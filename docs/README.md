# Affidavit documentation hub

`affidavit` is the provenance layer: it assembles and certifies provenance receipts —
append-only, content-addressed BLAKE3 chains of operation-events. The doctrine is
**certify, don't decide**. Project overview, install, and CLI: [`../README.md`](../README.md).
